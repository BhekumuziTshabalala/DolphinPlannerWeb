Set Up Firebase Cloud Sync

While Dolphin Planner is designed to be 100% offline and private by default, you can configure it to sync your study progress across multiple devices using your own personal Firebase database. Follow the guide below to connect the app to Firebase.

1

Create a Firebase Project

Go to the Firebase Console and click Add Project. Give it a name (e.g., "DolphinPlannerSync") and follow the setup wizard.

2

Register the Android App

In your Firebase project overview, click the Android icon to add an app. Enter the package name exactly as it appears in the source code:

com.iu.studytracker
3

Download google-services.json

After registering the app, download the configuration file google-services.json. Move this file into the app/ directory of your local Dolphin Planner source code folder.

4

Enable Cloud Firestore

In the Firebase Console menu, navigate to Firestore Database and click Create database. Start in Test mode for immediate access, or set up security rules to restrict read/write access to your authenticated user.

5

Rebuild the Application

Open the project in Android Studio and run a gradle sync. Build and install the APK to your devices. The app will now automatically detect the Firebase configuration and begin syncing your study plans and progress!

Note: Enabling Firebase sync overrides the default "offline-only" SQLite implementation. Ensure your Firebase Firestore rules are secure to keep your study data private.
