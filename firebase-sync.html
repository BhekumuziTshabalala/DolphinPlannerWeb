Set Up Firebase Cloud Sync (BYOF)

Dolphin Planner uses a unique "Bring Your Own Firebase" (BYOF) architecture. Instead of hardcoding credentials, the app allows you to link your own personal Firebase project to sync study data across your devices. Follow the timeline below to get started. Click on any image to enlarge it.

1

Create a Firebase Project

Navigate to the Console

Go to the official Firebase Console website.

Get Started

Click on the "Get started" or "Create a project" button to begin the setup wizard.

Name Your Project

Enter a descriptive name for your database, such as "DolphinPlannerSync", and accept the terms.

Finish Creation

Wait a few moments for Firebase to provision your backend resources, then click "Continue".

2

Enable Firestore Database

Locate Firestore

In the left-hand menu of your new project dashboard, click on "Firestore Database" under the Build category.

Create Database

Click the prominent "Create database" button to start the database setup wizard.

Configure Rules

Choose "Start in test mode" for immediate read/write access (you can secure these rules later), then click Next.

Select Location

Choose the cloud server region closest to you for the best sync performance.

Deploy Database

Click "Create" or "Enable" to finalize the database provisioning.

3

Add App & Extract Credentials

Return to Overview

Click on "Project Overview" (the home icon) in the top left corner of the menu.

Add an App

Look for the "Get started by adding Firebase to your app" section.

Select the Web Platform

Because the Android app uses dynamic API keys, you must click the Web (</>) icon.

Register the App

Give your app registration a nickname and click "Register app".

Copy Your Keys

Firebase will present a configuration block. These are the credentials you need to paste into the Dolphin Planner Android app!

Final Step: Link the App!

Open Dolphin Planner on your phone, go to Settings > Cloud Sync (Firebase), toggle it on, and paste in the Project ID, App ID, and Web API Key you retrieved from the last image.

Synchronization will begin immediately!

Why "Bring Your Own Firebase"?

The BYOF architecture puts you in complete control of your data and infrastructure.

Privacy First

Students own their data in their personal Google Cloud environment. No third party ever touches your study records or personal information.

Open Source Friendly

No leaked credentials or maxed-out quotas. Because each student uses their own project, the open-source repo stays clean and safe.

Offline-First

Room SQLite is the single source of truth. Firebase syncs opportunistically when connected — the app works perfectly without internet.
